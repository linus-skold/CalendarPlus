# CalendarPlus

[!["Buy Me A Coffee"](https://www.buymeacoffee.com/assets/img/custom_images/orange_img.png)](https://www.buymeacoffee.com/linus.skold)

A modern take on the World of Warcraft calendar. Displays ongoing events as a bar covering multiple dates instead off showing events starting on the reset day.
